# Tạo Cluster

Sau đó chọn "Kubernetes cluster". Không chọn "Automatic Kubernetes Cluster" - loại này không được hỗ trợ trên playground.

![image](../images/03-create-cluster.png)

> 💡 **Bổ sung:** "Automatic Kubernetes Cluster" (AKS Automatic) là chế độ mà Azure tự động quản lý cả node, scaling, bảo mật... thay bạn. Chế độ "Kubernetes cluster" (AKS Standard) cho phép bạn tự cấu hình node pool, phù hợp với giới hạn của playground.

Tiếp theo: [Cấu hình Cluster](./04-creation-form.md)
