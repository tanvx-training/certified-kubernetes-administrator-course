# Practice Test - Secrets (Bài thực hành)
  - Đi tới [Practice Test](https://kodekloud.com/topic/practice-test-secrets/)

Lời giải cho bài practice test - Secrets
- Chạy lệnh 'kubectl get secrets' và đếm số lượng Secret.
  
  <details>
  ```
  $ kubectl get secrets
  ```
  </details>
    
- Chạy lệnh 'kubectl get secrets' và xem cột DATA.

  <details>
  ```
  $ kubectl get secrets
  ```

  Cột `DATA` cho biết số lượng key (mục dữ liệu) trong Secret.
  </details>
  
- Chạy lệnh 'kubectl describe secret'

  <details>
  ```
  $ kubectl describe secret
  ```
  </details>
    
- Chạy lệnh 'kubectl describe secret'

  <details>
  ```
  $ kubectl describe secret
  ```

  > 💡 **Lưu ý:** `kubectl describe` chỉ hiện kích thước (bytes) của mỗi giá trị chứ không hiện nội dung. Muốn xem giá trị thật, dùng `kubectl get secret <tên> -o yaml` rồi decode base64.
  </details>
  
- Chúng tôi đã triển khai sẵn các Pod và Service cần thiết. Hãy kiểm tra các Pod và Service đã được tạo. Xem ứng dụng web qua link 'Webapp MySQL' phía trên terminal, cạnh link Quiz Portal.

- Chạy lệnh kubectl create secret generic db-secret --from-literal=DB_Host=sql01 --from-literal=DB_User=root --from-literal=DB_Password=password123

  <details>
  ```
  $ kubectl create secret generic db-secret --from-literal=DB_Host=sql01 --from-literal=DB_User=root --from-literal=DB_Password=password123
  ```
  </details>
  
- Kiểm tra đáp án tại /var/answers/answer-webapp.yaml

  <details>
  ```
  $ kubectl get pod webapp-pod -o yaml > web.yaml
  $ kubectl delete pod webapp-pod
  ```
  </details>
  
  Cập nhật web.yaml, thêm phần Secret (trong container)
  
  envFrom:
  - secretRef:
      name: db-secret
  
  <details>
  ```
  $ kubectl create -f web.yaml
  ```
  </details>

  > 💡 **Mẹo:** Có thể làm gọn hơn bằng `kubectl edit pod webapp-pod` → thêm `envFrom` → lưu (bị từ chối) → `kubectl replace --force -f /tmp/kubectl-edit-xxxx.yaml`.
  
- Xem ứng dụng web để xác nhận nó đã kết nối thành công tới database.
