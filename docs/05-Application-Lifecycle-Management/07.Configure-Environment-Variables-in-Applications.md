# Cấu hình biến môi trường cho ứng dụng (Configure Environment Variables in Applications)
  - Xem [Video hướng dẫn](https://kodekloud.com/topic/configure-environment-variables-in-applications/)
  
#### Biến môi trường (ENV) trong Docker
```
$ docker run -e APP_COLOR=pink simple-webapp-color
```

#### Biến môi trường trong Kubernetes
- Để đặt biến môi trường, khai báo thuộc tính **`env`** trong file định nghĩa Pod. `env` là một mảng; mỗi phần tử có `name` (tên biến) và `value` (giá trị).
  
  ```
  apiVersion: v1
  kind: Pod
  metadata:
    name: simple-webapp-color
  spec:
   containers:
   - name: simple-webapp-color
     image: simple-webapp-color
     ports:
     - containerPort: 8080
     env:
     - name: APP_COLOR
       value: pink
  ```
  ![env](../../images/env.PNG)
  
- Ngoài ra còn có các cách khác để đặt biến môi trường, như dùng **`ConfigMaps`** và **`Secrets`** (qua `valueFrom`)

  ![cms](../../images/cms.PNG)

> 💡 **Bổ sung:** Ngoài giá trị trực tiếp (`value`), `valueFrom` còn hỗ trợ:
> - `configMapKeyRef`: lấy giá trị từ một key của ConfigMap.
> - `secretKeyRef`: lấy giá trị từ một key của Secret.
> - `fieldRef` (Downward API): lấy thông tin của chính Pod, vd `metadata.name`, `metadata.namespace`, `status.podIP`, `spec.nodeName`.
> - `resourceFieldRef`: lấy requests/limits của container, vd `limits.memory`.
>
> Kiểm tra biến môi trường trong container đang chạy: `kubectl exec <pod> -- env`. Lưu ý: giá trị như `true`, `8080` nên đặt trong dấu nháy (`"8080"`) vì `value` phải là string.
