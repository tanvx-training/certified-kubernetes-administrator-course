# Cập nhật quan trọng về Kubernetes the Hard Way
  
  - Xem [Trang cập nhật](https://kodekloud.com/topic/important-update-kubernetes-the-hard-way/)

> 💡 **Bổ sung:** "Kubernetes the Hard Way" (của Kelsey Hightower) là hướng dẫn cài đặt cluster thủ công từng thành phần: tự tạo CA và certificate, tự cấu hình kubeconfig, etcd, kube-apiserver, kube-controller-manager, kube-scheduler, kubelet, kube-proxy dưới dạng systemd service... Cách làm này giúp hiểu sâu cách các thành phần giao tiếp với nhau. Kỳ thi CKA không yêu cầu cài đặt cluster theo cách này. Phiên bản do KodeKloud duy trì (dùng VirtualBox/Vagrant) có tại https://github.com/mmumshad/kubernetes-the-hard-way.
